## How to Get Started in 30 Seconds

1. Extract the downloaded ZIP archive.
2. Open the folder: **`ATS-Resume-Studio`** ➔ **`ATS-Resume-Studio-App/`**
3. **On Mac:** Double-click **`start-mac.command`**
   *(If prompted by macOS Gatekeeper, right-click and select "Open".)*
4. **On Windows:** Double-click **`start-windows.bat`**
5. Your browser will automatically open to `http://127.0.0.1:3000/app/` with the complete studio ready to use!
6. Leave the small terminal window open in the background while using the app.

*For detailed instructions, template styling, and export guides, read **`QUICKSTART.md`**.*
